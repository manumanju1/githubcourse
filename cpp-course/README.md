# C++ Course Repository

This repository contains a beginner-friendly C++ course with examples, exercises, and a project scaffold.

## Course Modules

1. Basics: syntax, variables, I/O, and simple types
2. Control Flow: conditionals, loops, and branching
3. Functions and Classes: modular code and object-oriented fundamentals
4. Templates and STL: generic programming and standard library usage
5. Modern C++: smart pointers, move semantics, and best practices

## Getting Started

```bash
mkdir build
cd build
cmake ..
cmake --build .
./cpp-course
```

## Structure

- `src/`: main application and example code
- `include/`: reusable headers
- `exercises/`: lesson-based exercise content
- `CMakeLists.txt`: build configuration
- `.gitignore`: ignore build artifacts
